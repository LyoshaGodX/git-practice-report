# Памятка по базовым операциям Git

## Просмотр состояния

```bash
git status
git log --oneline --graph --decorate --all
```

`git status` показывает текущую ветку и изменения в рабочем каталоге. `git log` в указанном формате наглядно отображает историю и связи между ветками.

## Создание коммита

```bash
git add <файл>
git commit -m "Краткое описание изменения"
```

Коммит фиксирует подготовленные изменения в истории локального репозитория.

## Работа с ветками

```bash
git switch -c <имя-ветки>
git switch main
git branch --all
```

Отдельная ветка позволяет выполнять изменения независимо от основной линии разработки.

## Слияние

```bash
git switch main
git merge --no-ff <имя-ветки>
```

Параметр `--no-ff` сохраняет в истории отдельный merge-коммит, поэтому факт объединения веток легко увидеть на графе.

## Работа с GitHub

```bash
git remote -v
git push -u origin <имя-ветки>
git clone <адрес-репозитория>
```

Команда `push` отправляет локальные коммиты в GitHub, а `clone` создаёт новое локальное рабочее представление удалённого репозитория.
